Illust...later 操作マニュアル

初めて使う人向けのガイドです。画面の見方から、図形を描く、色を付ける、文字を入力する、作品を保存するまでを順に説明します。まず「画面の見方」と「最初の作品」から試してください。

画面の図解は操作する場所を示すために簡略化しています。旧画面のスクリーンショットには、現在と異なる表示があります。

第 01 章

画面の見方と最初の準備

Illust...laterは、線や図形を組み合わせてイラストやロゴを作るアプリです。Macではクリック、iPadではタップで同じ手順を進められます。このマニュアルでは、両方を「選ぶ」と表記します。

  1. 最上段のメニュー

    ファイルを開く・保存する、編集を取り消す、パネルを呼び出すときに使います。まず「ファイル → 新規…」を選び、練習用に幅800・高さ600 pxを指定します。

  2. 上部の設定バー

    使用中のツールや選択した図形に応じて項目が変わります。線幅を変えたいときは図形を選択し、文字のサイズを変えたいときは文字を選択します。

  3. 左ツールバーと中央

    左で描く道具を選び、中央の白いアートボードで操作します。見当たらないツールは「…」を開きます。

  4. 右のタブ

    「プロパティ」は設定、「レイヤー」は図形の前後・表示、「スウォッチ」は色や模様の見本です。右側が閉じている場合は上部の「プロパティ」またはウィンドウメニューから表示します。

ポイント　まずは第2章でバッジを1つ作り、第9章で編集用ファイルと画像を保存してみましょう。

第 02 章

最初の作品 丸いバッジを作る

楕円を1つ描き、塗りと線を別々に設定します。塗りは内側の色、線は輪郭です。

  1. 楕円を描く

    左ツールバーで楕円を選び、白い領域で斜めにドラッグします。まずは同じくらいの幅と高さを目安にし、正確な寸法はプロパティで設定します。

  2. 内側を青、輪郭を白にする

    黒い矢印の「選択」に切り替え、楕円をタップします。上部の「塗」の色を青にし、「線」を有効にして白を選びます。線幅は8 pxから試します。

  3. 大きさと位置を変える

    中央付近をドラッグすると移動、選択枠の四隅をドラッグすると拡大・縮小します。数値欄をタップすると、対応する欄ではスライダーからも調整できます。

  4. 色をなくす

    左ツールバー下で「塗」または「線」を選び、赤い斜線の「なし」を選びます。白は色、斜線は透明です。

ポイント　間違えたときは「編集 → 取り消し」。項目名の後ろに、戻す操作が表示されます。

第 03 章

パスとアンカーを編集する

パスは図形を形づくる線です。アンカーは線の通過点、ハンドルは曲線の向きと曲がり方を調整する取っ手です。

  1. 曲線を描く

    ペンツールで点を順に置きます。タップで角、押してドラッグすると曲線の方向を指定できます。閉じた形を作るなら最初の点を選びます。手書きに近い線は鉛筆を使います。

  2. アンカーを動かす

    白い矢印の「ダイレクト選択」でパスを選び、青い四角をドラッグします。ハンドルは選んだ点と、その点に直接つながる点に表示されます。丸い取っ手を動かすと通過点の位置を保ったまま曲がり方を変えられます。

  3. 輪郭に穴を作る

    内側と外側の輪郭を選択し、「オブジェクト → パス・複合パス…」を開きます。複合パスは複数の輪郭を1つの図形として扱い、塗りの規則で内側を穴にできます。

  4. アンカーを減らす

    細かい点が多くて編集しにくいときは、パスを選び「選択パスのアンカーを減らす」を試します。簡略化後は、角や細部が意図どおりか拡大して確認します。

ポイント　「線のアウトラインを作成」は、線の太さを塗りの輪郭に変える操作です。「表示 → アウトライン」は確認用の表示切替です。

第 04 章

重なりとレイヤーを管理する

レイヤーは透明なシートのようなものです。線画、色、文字を分けておくと、どれかを隠したり保護したりできます。

  1. レイヤーを切り替える

    右の「レイヤー」タブで追加ボタンを選びます。レイヤー名を選ぶと次に描く図形の作業先になります。親の目をオフにすると効果付きの図形も隠れます。再表示すると、個別に非表示にしたパスは隠れたままです。鍵は編集の可否を切り替えます。

  2. 重なりを変える

    図形を選び、「オブジェクト → 前面へ」などを使います。「前面へ」は1段、「最前面へ」は一番手前に移します。参照用の下絵は専用レイヤーで最背面に表示されます。

  3. 複製する

    「編集 → コピー」の後に「貼り付け」、または「複製」を使います。MacではOptionを押してドラッグ、iPadでは「選択 → 複製して移動」をオンにしてドラッグできます。

  4. 位置を揃える

    複数選択して「オブジェクト → 整列・分布…」。整列は端や中心を揃え、分布は間隔を均等にします。基準オブジェクトを使うと、基準の図形を動かさず他を揃えられます。

ポイント　形をまとめて動かしたい場合は「グループ」、重なりを計算して新しい輪郭にしたい場合は「パスファインダー」を使います。

第 05 章

グラデーションとブラシと模様

グラデーションは色の変化、ブラシは線に沿う装飾、パターンは図形の内側に敷き詰める模様です。いずれもスウォッチのプリセットから試せます。

  1. グラデーションを適用する

    図形を選択し、右の「スウォッチ」で「塗り」か「線」を指定してグラデーションのプリセットを選びます。調整は「ウィンドウ → グラデーション」または左ツールのグラデーション編集から行います。

  2. 色の途中を変える

    色の帯にある丸がカラーストップです。丸を動かすと色の位置、選択した丸の「色」「不透明度」で色と透け具合が変わります。色の帯をタップして点を追加できます。

  3. ブラシで描く

    左のブラシを選び、プリセットを選んでキャンバスをドラッグします。アートは原型を伸ばし、パターンブラシは繰り返し、散布は原型を線の周りに散らします。

  4. 図形に模様を敷く

    図形を選び、スウォッチの「パターンのプリセット」を選びます。自作する場合は「オブジェクト → パターン…」から原型を登録します。

ポイント　色が変わらないときは、図形の選択と塗り／線の指定を確認します。3Dでは効果の素材色が表示に関係します。

第 06 章

文字を直接入力して配置する

文字はキャンバス上で入力します。編集後は上部の「確定」を選びます。漢字変換中は、先に変換候補を確定してください。

  1. 横書きと縦書き

    横書きは左の「T」、縦書きは左の縦書き文字ツールを選択。キャンバスをタップして入力し、上部で書体・サイズ・色を変更します。縦中横は縦書きの中で短い数字などを横並びにする設定です。

  2. 図形の内側に流す

    塗りのある閉じた図形を用意し、「書式 → エリア内文字」を選んで図形をタップします。文字は輪郭に合わせて折り返します。あふれたら図形を広げるか、文字サイズや行間を調整します。

  3. 線に沿わせる

    ペンや鉛筆でパスを1本作り、「書式 → パス上文字ツール」でパスをタップして入力します。作成後は文字を選択し、「書式 → パス上文字のパスを編集」で経路のアンカーを動かします。

  4. 書体を選ぶ・輪郭に変える

    上部の書体欄は日本語・欧文を分けて表示します。追加は「書式 → フォント…」。文字を図形として渡す場合は、文字を選び「書式 → アウトラインを作成」。変換前の編集用コピーも残します。

ポイント　アウトライン化した文字は、文字入力や書体の変更ができなくなります。

第 07 章

下絵を読み込んで画像トレースする

画像トレースは画像の画素を、編集できるパスに変換します。PNGを配置するだけではパスになりません。

  1. 下絵を置く

    「ファイル → 画像トレース…」の「画像を選択 または ドロップ」で画像を配置します。下絵の不透明度を下げると手動でなぞる場合に便利です。

  2. 用途に近いプリセットを選ぶ

    ロゴなら「白黒ロゴ」、薄い線画なら「鉛筆・薄い線画」、色数の少ない絵なら「4色アイコン」「8色イラスト」から始めます。

  3. プレビューを見ながら調整する

    白黒のしきい値を上げると明るめの画素も黒になり、線が残りやすくなります。紙の影は「照明むらを補正」。カラーは色数と「カラーの強度」で、似た色をまとめる度合いを調整します。

  4. 確定して不要な形を確認する

    「トレースを確定」を押し、レイヤーで下絵を隠してパスだけを確認します。点が多すぎるときは「細かいゴミ除去」を上げるか「輪郭の精度」を下げます。カラーのパスを再編集するには、JSONプロジェクトを保存します。

ポイント　編集可能なSVGを持っている場合は「SVG・PDF・AIを読み込む…」を使うと、トレースせずに元のパスを取り込める場合があります。

第 08 章

形を組み合わせて効果を付ける

重なりを編集する操作と、元の図形を保って見え方を変える効果を使い分けます。

  1. 重なる図形から新しい形を作る

    複数の図形を選択し、「オブジェクト → パスファインダー…」。合体は全体、前面で型抜きは背面から重なりを削除、交差は共通部分、中マドは重なりを除いた部分を残します。

  2. Shaperとブレンド

    Shaperは手描きの輪郭を図形に変換し、ジグザグの操作で重なりを編集します。ブレンドは2つの図形を順に選んで中間の形と色を作ります。「ブレンド設定」で間隔・方向・イージングを調整します。

  3. ぼかしと回転体

    図形を選び「効果 → ぼかし」から設定します。広がりとトリミングは第14章を参照してください。立体は「効果 → 3Dとマテリアル → 回転体…」で、回転範囲や滑らかさを調整します。

  4. 効果を後から編集する

    数値や素材は変更した時点で反映されます。3D図形を選んでプロパティの「3Dとマテリアルの設定…」を開くと続きから調整できます。操作を戻すには「編集 → 取り消し」。

ポイント　ベベルは角の面取り、マテリアルは表面の質感、環境光は影側も照らす補助光です。

第 09 章

編集用に保存して作品を書き出す

同じ作品でも、あとで編集するファイルと、相手に渡すファイルを分けて保存すると作業が楽になります。

  1. 編集用ファイルを保存する

    「ファイル → プロジェクトを保存」でJSONを保存します。別の名前なら「別名で保存…」。開くときは「ファイル → プロジェクトを開く…」を選びます。保存・読み込みの上限は128 MiBです。旧版で64 MiBを超えるファイルが開かなかった場合は、アプリを開き直して試してください。

  2. 作品を渡す形式を選ぶ

    SVGはベクター図形を渡すとき、PNGは透明背景の画像、JPEGは写真などの背景付き画像、PDFは閲覧や印刷に使います。書き出す前に「出力プレビュー…」で範囲と見え方を確認します。

  3. アートボードを確認する

    アートボードは出力範囲の基準です。必要に応じて「書き出しアートボード…」や書き出し設定で範囲を確認します。印刷先から指定がある場合は「印刷・PDF設定…」で条件を合わせます。

  4. VIBridgeに渡す

    出力プレビューでSVGコードやData URIを確認できます。VIBridgeに貼り付ける場合は、貼り付け先が受け付ける形式を選びます。

ポイント　納品前は、書き出したファイルを開き直し、文字・透明部分・切り抜き範囲を確認してください。

第 10 章

iPadでの操作と困ったとき

キーボードがなくても、メニュー、パネル、画面のボタンから基本操作を進められます。

  1. ヘルプを使う

    「ヘルプ → ？ヘルプ」をオンにして、項目をタップします。「ヘルプを終了（Q）」で通常の操作に戻ります。同じメニューから操作マニュアルとショートカット一覧も開けます。

  2. iPadで数値・画面を操作する

    数値欄をタップすると、対応する項目ではスライダーが開きます。キャンバスをピンチして拡大縮小し、手のひらツールで表示位置を移動できます。

  3. タッチキーを増やす

    「表示 → タッチキー設定…」で1列・2列・非表示を選び、「段を追加」でキーを置く位置を増やします。収まらないキーは左ツールバー下の「…」で開きます。ShiftやOptionは長押し、または「次の1操作」に設定できます。

  4. 操作できないとき

    図形が選択され、レイヤーが表示中でロックされていないか確認します。ヘルプ資料はアプリ内で移動・拡大縮小・最小化でき、資料の上部から別タブにも開けます。

ポイント　正円を描く例。タッチキーのShiftを長押ししながら、別の指で楕円をドラッグします。

第 11 章

用途別のツール早見表

「何をしたいか」から道具を選びます。まず作品のコピーで試すと、違いを見比べやすくなります。

  1. 一部分を消す

    左の消しゴムで消したい部分をなぞります。丸いカーソルが範囲の目安です。図形を丸ごと消すときは選択して「編集 → 削除」。部分消去を戻す項目は「オブジェクト → クリッピングマスク・部分消去…」にあります。

  2. 窓の中だけ見せる

    クリッピングマスクは切り抜きの窓です。前面に窓の形を置き、背後の絵と一緒に選択してマスクを作ります。元の絵を削らず、窓の外を隠します。

  3. 補助線に揃える

    「表示」から定規・ガイドやグリッドを表示します。吸着を使うと図形が近くの目印に揃います。遠近グリッドは一点・二点・三点を選べます。左上のキューブで面を指定し、長方形などを描くとその面に沿います。

  4. 同じ部品を繰り返し使う

    シンボルは元の図形を登録し、リンクした配置先で使う仕組みです。アピアランスは1つの図形に複数の塗りや線を重ねる仕組みです。どちらも「オブジェクト」から設定を開けます。

ポイント　シェイプ形成ツールは重なった図形の面を選んで結合・削除する道具です。自由に描いて図形へ変換するShaperとは役割が異なります。

第 12 章

遠近グリッドを使って描く

遠近グリッドは、奥行きのある形を描くための補助線です。線が遠くで集まる場所を消失点と呼びます。

  1. 透視の種類と面を選ぶ

    「表示 → 遠近グリッド」で一点・二点・三点を選びます。左上のキューブで左面、右面、水平面を選びます。一点透視では右面は選べません。「平面」を押すと通常の図形を描けます。

  2. 消失点を動かす

    二点透視では左右の丸を地平線に沿って動かします。三点透視では第3消失点を上下左右に動かせます。画面外の点は端の丸から調整できます。地平線と原点も個別に動かせます。

  3. 設定を見ながら調整する

    キューブ下の「設定」を開くと、視角・視距離・消失点などの変更がその場で線に反映されます。消失点が設定範囲に達すると視距離を一時調整し、視角を戻すと元の距離に戻ります。「適用」で確定、「キャンセル」で変更前に戻ります。

  4. 補助線に吸着させる

    「表示 → 遠近グリッド → 遠近グリッドに吸着」をオンにします。選んだ面の線や交点の近くで、長方形などの始点と終点が揃います。移動や拡大縮小では選択枠が吸着します。

ポイント　二点透視のマス目は投影前に正方形です。画面上では奥へ向く面ほど縮んで見えます。

第 13 章

キャンバスで回転や変形を行う

先に選択ツールで図形を選び、左ツールバーの「…」から道具を選びます。「オブジェクト → 変形ツール」からも開けます。

  1. 回転する

    「回転ツール」を選び、キャンバスで基準点を置きます。その点の周りをドラッグします。Shiftで15°刻みになります。ショートカットはRです。

  2. 鏡像を作る

    「リフレクトツール」を選び、軸の上を2点タップするか、軸に沿ってドラッグします。選択枠は図形に追従します。ドラッグ中は元の位置からの移動角が表示され、Shiftで90°刻みに揃います。ショートカットはOです。

  3. 平行四辺形のように傾ける

    「シアーツール」を選び、上部で水平・垂直を選びます。キャンバスで基準点を置き、指定した方向にドラッグします。

  4. ピンを使って一部を曲げる

    「パペットワープツール」でピンを2つ以上置き、固定するピンを残して別のピンをドラッグします。「編集完了」でピンを保持し、「展開」で通常のパスに確定します。

ポイント　パペットワープは通常の単色図形1つに使えます。文字は先にアウトライン化します。保存後は図形を選び直し、同じツールでピンを編集できます。

第 14 章

ぼかしの広がりと境界を調整する

「効果 → ぼかし → ぼかし（ガウス）…」は図形全体をぼかします。輪郭を透けさせたいときは「効果 → スタイライズ → ぼかし（境界）…」を選びます。

  1. 横と縦の広がりを決める

    「縦横の連動」で「横と縦を別々に設定」を選びます。最初の半径が横方向、「縦の半径」が上下方向です。

  2. ぼかしを除外する辺を選ぶ

    「トリミング → 辺ごとにぼかしを除外」を選びます。「左から除外」を上げると左側からぼかしを取り除き、元の輪郭が見えます。右・上・下も個別に設定でき、0の辺は制限しません。

  3. 境界を切り替える

    「くっきり」は指定位置で切り替えます。「なだらか」は指定位置から内側に向かってぼかしを徐々に強めます。「切り替え幅 px」を上げると、徐々に変化する区間が長くなります。

  4. 影の広がりを調整する

    「効果 → スタイライズ → ドロップシャドウ…」でも縦横のぼかし幅を調整できます。「図形の外接枠＋余白」で、上下左右に指定した余白まで影を残します。

ポイント　設定はキャンバスに反映されます。あとから調整するときは、図形を選び直し、「効果」メニューから同じ効果を開きます。
